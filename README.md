# Alerts skill customization

CommerceIQ frontend prototype (Next.js + `@ciq-dev/ciq-design-system`).

## Setup

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Project docs

- [`product-context.md`](./product-context.md) — what to build (fill in **This prototype** first)
- [`instructions.md`](./instructions.md) — design-system and UI rules for builders and agents
- [`processguide.md`](./processguide.md) — scaffold checklist used to create this repo

## Stack

- Next.js (App Router, `src/`)
- Tailwind CSS 4
- [@ciq-dev/ciq-design-system](https://www.npmjs.com/package/@ciq-dev/ciq-design-system)
